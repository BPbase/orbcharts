# Encoding

`Encoding` 是 OrbCharts 的「欄位對應層」:它決定 `RawData` 中的哪個欄位對應到圖表的哪個**資料維度**(dataset、series、category、value 等),並可在過程中改欄位名、排序、做聚合。換句話說,你不必為了符合圖表而改寫資料,而是用 Encoding 把現有資料**對映**進來。

Encoding 在建立圖表時透過 `encoding` 選項傳入,也可之後用 `chart.updateEncoding()` 動態調整。資料本身的格式請見 [資料格式總覽](/docs/data-formats/overview)。

## Encoding 結構

```ts
interface Encoding {
  dataset:  { from: string; sort: 'original' | 'alphabetical' | string[]; ignore?: boolean }
  series:   { from: string; sort: 'original' | 'alphabetical' | string[]; ignore?: boolean }
  category: { from: string; sort: 'original' | 'alphabetical' | string[]; ignore?: boolean }
  value:    { from: string; sort: 'original' | 'asc' | 'desc'; aggregate: 'sum' | 'mean' | 'median' | 'min' | 'max' | 'count' | 'none' }
  multivariate: Array<{ from: string; name: string }>
  color:    { by: 'index' | 'series' | 'category' | 'dataset' }
}
```

| 維度 | 用途 | `from` 預設 | `sort` 預設 |
|---|---|---|---|
| `dataset` | 資料集分組(二維 `RawData`) | `'dataset'` | `'original'` |
| `series` | 系列分組(常用於上色、圖例) | `'series'` | `'original'` |
| `category` | 類別分組(常用於座標軸) | `'category'` | `'original'` |
| `value` | 數值欄位 | `'value'` | `'original'` |
| `multivariate` | 多變量欄位陣列 | — | — |
| `color` | 取色依據 | — | — |

### 各欄位預設值

- 各維度的 `from` 預設與維度**同名**(例如 `series.from` 預設為 `'series'`)。
- 各維度的 `sort` 預設為 `'original'`(維持原始順序)。
- `dataset`／`series`／`category` 的 `ignore` 預設為 `false`(不忽略,見下方[忽略某個維度](#忽略某個維度))。
- `value.aggregate` 預設為 `'none'`(不聚合)。
- `multivariate` 預設為 `[{ from: 'x', name: 'x' }, { from: 'y', name: 'y' }, { from: 'z', name: 'z' }]`。
- `color.by` 預設為 `'series'`(依系列上色)。

> **提示**:Encoding 採**深層合併**。用 `updateEncoding` 時只需寫出想改的欄位,其餘維度與設定都會沿用預設。

## 改欄位名

當資料的欄位名與預設不同時,用 `from` 指向實際欄位。例如資料用 `amount` 而非 `value`:

```ts
import { OrbCharts } from '@orbcharts/core'
import type { RawData } from '@orbcharts/core'

const data: RawData = [
  { series: 'A', amount: 30 },
  { series: 'B', amount: 70 },
]

const chart = new OrbCharts(element, {
  data,
  encoding: {
    value: { from: 'amount' },
  },
})
```

如此一來 `amount` 欄位就會被當作數值維度使用。

## 排序

`sort` 控制該維度的排列順序:

```ts
chart.updateEncoding({
  category: { sort: 'alphabetical' },  // 類別依字母排序
  value:    { sort: 'desc' },          // 數值由大到小
})
```

- `dataset` / `series` / `category` 支援 `'original'`、`'alphabetical'`,或自訂順序的 `string[]`。
- `value` 支援 `'original'`、`'asc'`、`'desc'`。

```ts
// 以自訂順序排列 series
chart.updateEncoding({
  series: { sort: ['北區', '中區', '南區'] },
})
```

## 聚合

`value.aggregate` 會在同一分組內把多筆數值合併成一個值,適合原始資料較細、需要彙總的情況:

```ts
chart.updateEncoding({
  value: { aggregate: 'sum' },  // 同分組數值加總
})
```

可用的聚合方式:

| 值 | 說明 |
|---|---|
| `'sum'` | 加總 |
| `'mean'` | 平均 |
| `'median'` | 中位數 |
| `'min'` | 最小值 |
| `'max'` | 最大值 |
| `'count'` | 筆數 |
| `'none'` | 不聚合(預設) |

## 忽略某個維度

`dataset`／`series`／`category` 都可以設定 `ignore: true`,代表計算時完全不讀取該維度對應的原始欄位,所有資料在這個維度上會被視為同一組。

> **注意**:單獨設定 `ignore: true` **不會**合併資料——它只是讓原本不同組的資料變成同一組,每一筆資料仍然各自輸出一筆 ModelData。真正把同一組資料合併成一筆的是 `value.aggregate`。也就是說,`ignore` 決定「什麼算同一組」,`aggregate` 決定「同一組要不要合併、怎麼合併」,**兩者要一起設定**才能達到「忽略某個維度、把資料合併」的效果。

一個常見情境:同一份 series × category 的資料,想在長條圖裡讓每個 series × category 各自獨立顯示,但切換成圓餅圖時想依 series 把所有 category 加總成一筆:

```ts
// 長條圖：series × category 各自獨立（預設行為）
chart.updateEncoding({ value: { aggregate: 'none' } })

// 圓餅圖：忽略 category，同一 series 全部加總成一筆
chart.updateEncoding({
  category: { ignore: true },
  value: { aggregate: 'sum' },
})
```

被 `ignore` 的維度,輸出的 ModelData 中對應欄位(例如 `category`／`categoryIndex`)會是空字串／`0`,代表「此維度不適用」。

## 動態調整

```ts
chart.updateEncoding({ value: { from: 'amount' } })  // 局部更新(深層合併)
chart.getEncoding()                                   // 取得目前 Encoding(唯讀)
chart.forceReplaceEncoding(fullEncoding)              // 完整取代
```

詳見 [OrbCharts 類別](/docs/api/orbcharts-class) 中的 `updateEncoding` / `forceReplaceEncoding` / `getEncoding`。
